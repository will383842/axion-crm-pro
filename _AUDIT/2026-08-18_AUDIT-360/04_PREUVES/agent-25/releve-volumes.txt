Le second essai, avec --max-old-space-size=8192, ne meurt plus : il n en finit pas.

CE QUE CELA VEUT DIRE POUR UN NAVIGATEUR, ET QUI EST LE VRAI POINT :
  React construit ce DOM dans un rendu SYNCHRONE. Rien ne peut l interrompre —
  ni le timeout de vitest, ni un `waitFor`, ni, dans un navigateur, l utilisateur.
  L onglet est fige, sans sablier et sans message, tant que le rendu n a pas fini.
  Ce n est donc pas « c est lent » : c est « la page ne repond plus ».
