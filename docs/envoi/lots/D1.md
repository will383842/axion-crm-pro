# D1 — dettes de la relève IMAP (M3)

## Fait
- **Empreinte d'adresse** : `AdresseParEmpreinteCrm` pré-sélectionne en SQL (fonction `empreinte_adresse_sql`, IMMUTABLE, mêmes blancs retirés que `trim()` de PHP : espace, tabulation, LF, CR, VT) puis **recalcule chaque candidat avec `ListeSuppression::empreinte()`** : une seule fonction fait foi.
- **Index** : migration `2026_12_02_000200` (fonction + `CREATE INDEX … (workspace_id, empreinte_adresse_sql(email))` partiel, CONCURRENTLY hors transaction, ajout seul, `down()` inerte, `up()` rejouable). Un test lit le plan (`EXPLAIN`).
- **Réponse automatique** : un message à objet d'absence/congé/accusé de réception (ou `Precedence: bulk/junk`) dont le texte non cité dépasse 40 caractères est classé `auto_reponse` AVANT la recherche de STOP et de plainte. Aucune opposition, aucun arrêt d'entreprise. Un texte court (« STOP ») reste un STOP.
- **Injection** : tests de non-doublon (plusieurs lignes du même destinataire = une origine, rejeu de la relève = un seul événement ; destinataires différents = « à rattacher »).
- **3e maillon** : test rebond dur ×3 → compteur → frein `rebonds_durs_trop_nombreux` → pause ouverte.

## Reste / non fait (décision à prendre)
- **Index UNIQUE sur `envoi_messages_envoyes (workspace, injection, destinataire)` : NON posé.** Un test existant (`registre base : plusieurs lignes du MÊME destinataire…`) tient ce cas pour légitime ; l'index le contredirait et pourrait échouer sur des données existantes. L'unicité effective repose sur `envoi_evenements` (index uniques par UID et par empreinte de message). ESCALADE données si le propriétaire veut l'unicité.
- « Absence (pause) » : l'état « en pause » d'une inscription n'existe pas (voir `RecepteurRetoursSequence`) ; l'absence est donc classée `auto_reponse`, sans effet. Aucune migration ajoutée pour cela.
- Les majuscules non ASCII dépendent de la locale de la base pour `lower()` : en cas d'écart, retour « à rattacher » (jamais une mauvaise adresse).

## Risques / points pour relecture
- Un vrai STOP long sous un objet d'« absence » serait classé absence (compromis voulu par la consigne ; seuil de 40 caractères, constante `TEXTE_COURT_MAX`).
- `NR17_RETOUR_INERTE_VOULU` complétée d'une ligne motivée (« Filet modifié : pourquoi ») pour la migration au `down()` inerte.
- Conteneurs mixtes en production : fonction et index ajoutés, ignorés par l'ancien code.
