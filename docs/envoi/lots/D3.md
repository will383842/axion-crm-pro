# D3 — Dettes de la garde produit et de l'écran boîtes

Branche `feat/d3-dettes-garde-produit` (depuis `origin/main`, aucune PR ouverte, aucun workflow lancé).

## Fait
- **Verrou de ligne** : `WorkspaceController::update` lit et écrit `workspaces` dans une seule transaction, ligne prise `FOR UPDATE`. Une suspension posée en console entre la lecture et l'écriture n'est plus écrasée.
- **`produits:suspendre {espace} {produit}`** : symétrique de `produits:activer` (uuid ou slug, ligne verrouillée, idempotente, journalisée, autres réglages conservés). Ne suspend qu'un produit `actif` (produit jamais activé ou résilié : refus). Aucune route.
- **`GET /config/features`** publie `produits` (`crm` toujours `actif`, `envoi` lu via `ProduitsEspace`, fermé par défaut). Le contrat (`Features.produits` dans `commun.yaml`), les `.d.ts` et le handler de démo le portaient déjà : la réponse réelle est maintenant validée par `ContratOpenApiEnvoi`.
- **Garde `produit-envoi`** : `suspendu` → 403 `produit_suspendu`, `resilie` → 403 `produit_resilie` (texte français) ; `absent` et valeur inconnue restent 404.
- **Frontend** : un échec de `/auth/me` affiche « Vos droits n’ont pas pu être vérifiés (connexion interrompue) » au lieu de « Il vous manque la permission… » (`useDroitsBoites().erreur`, `messageDroits`).

## Reste / risques / à relire
- **Test existant modifié** (`ProduitEnvoiTest`) : le cas « suspendu/résilié → 404 » est scindé : inconnu/absent restent 404 (inchangé), suspendu/résilié attendent 403 clair (assertion plus précise, rien de supprimé). Choix prudent, à valider.
- `commun.yaml` (description d'`EtatProduit`, « 404 sinon ») n'est pas touché (réservé à R02/R14) : sa description est à aligner sur le 403.
- Le frontend ne traite pas encore spécialement le 403 `produit_suspendu` (message générique) : à voir avec le design.
- Si `If-Match` est utilisé, une suspension change `updated_at` : le client reçoit alors 409 (voulu).
- Réactivation d'un produit suspendu = `produits:activer` (inchangé). Résiliation : pas de commande (décision propriétaire).
- `ENVOI_REEL_ACTIF`, mode témoins, `envoi_drapeaux` non touchés.
