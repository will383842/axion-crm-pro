# R06-D — Code SMTP dans les tentatives

## Fait
- `ResultatInjection` porte un `?int $codeSmtp` (facultatif, 200 à 599 ; hors bornes : `InvalidArgumentException` à la construction). `reporteEchec()` l'accepte en second argument.
- `RefusDefinitifServeur` porte le même `?int $codeSmtp`, validé de la même façon.
- `PasserelleLocale` transmet le code à `DepotTentatives::noter` : refus définitif => `refusee` + code ; report d'échec => `reportee` + code. Un report d'attente local (plafond, pause) n'écrit toujours aucune tentative.
- `FauxServeurEnvoi` : `refuserDefinitivement(int)` et `reporterEchec(?int)` pour les scénarios de test.
- `LecteurReportsDbTest` : retrait de `$serveur` et `$p` inutilisés dans le test « annulation… » (assertion inchangée).
- `DepotTentatives` : non modifié (accepte déjà `?int $codeSmtp`).

## Reste
- `AdaptateurSmtp` et `ServeurEnvoiKumo` construisent encore `RefusDefinitifServeur` sans code (hors liste fermée de cette PR) : à brancher dans une PR dédiée.

## Risques
- Aucun : pas de route, pas de migration, `ENVOI_REEL_ACTIF=false` inchangé.
