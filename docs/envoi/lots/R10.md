## Fait
- Routes (fichier `backend/routes/envoi/creation.php`) : `GET`/`POST /envoi/messages`, `GET`/`PUT /envoi/messages/{id}`, `POST …/versions/{numero}/restaurer`, `POST …/versions/{numero}/valider`, `POST …/archivage`, `GET /envoi/creation/contexte`, `POST /envoi/creation/champs`, `POST /envoi/messages/controler`, `/apercu`, `/test` (409 `envoi_ferme_palier_0`), `/suggestion` (501 `non_disponible`).
- Code : `App\Envoi\Creation\ServiceMessagesTypes` (réutilise `DepotModeles`, `ControleurContenu`, `HtmlListeBlanche`, `ComposeurMessage::rendre` en rendu seul) et `EnvoiMessagesController`. Aucune migration.
- Permissions : lecture et outils `users.manage` (propriétaire, administrateur) ; écriture (créer, enregistrer, restaurer, valider, archiver) `workspaces.manage` (propriétaire seul). Opérateur et lecteur : 403.
- Contrat : `creation.yaml` amendé (réponses 409 pour `test`, 501 pour `suggestion`, 422 pour la création) ; `creation.d.ts` régénéré ; instantané des routes mis à jour (ajouts seuls).
- `PUT` crée toujours une nouvelle version et ramène le modèle à brouillon (la version validée n'est jamais modifiée) ; `valider` n'accepte que la dernière version, sous verrou consultatif + verrou de ligne, et enchaîne brouillon → à relire → validé ; l'archivage est définitif (aucune route DELETE, désarchiver répond 409).

## Reste / non fait (notés, prudents)
- Clé `Idempotency-Key` : non gardée en base (aucune migration permise dans ce lot).
- `objet_b` (test A/B) et `bloc_information=false` : refusés en 422, car aucune colonne ne les porte ; `bloc_information` est donc toujours vrai dans les réponses.
- `blocs` (blocs réutilisables) : liste vide, aucune source ; `utilise_par` : 0 (aucun lien campagne ↔ modèle dans ce lot).
- `champs` : `manquants` vaut 0 (la cible n'est pas parcourue) ; tous les champs ont un repli obligatoire, donc jamais bloquants.
- `apercu` : destinataire exemple non lu, valeurs de repli seulement ; expéditeur fictif `exemple.test`.
- Journal : trace `Log::info('envoi.messages_types')` sans contenu (qui, geste, modèle) ; pas de table de journal dédiée (pas de migration).
- Démo : les handlers de démo de `test` et `suggestion` renvoient encore 200 (le contrat garde le 200 documenté) ; l'écran devra gérer 409/501 dans un lot front. Test à deux connexions non écrit (aucun geste ne croise un frein).
- Décision du propriétaire : ouvrir `suggestion` = ESCALADE argent et données (modèle d'IA tiers).
