## Risques
- Orange est rangé sous `autre` (le CHECK de `envoi_pauses.fournisseur` n'a que gmail, microsoft, autre) : une mauvaise réputation Orange freine donc aussi les autres fournisseurs hors Gmail et Microsoft (le plus prudent). Élargir ce CHECK serait une ESCALADE données, non faite.
- Une pause ouverte par réputation ne se lève que par la voie humaine existante (`envoi:lever-pause`) : aucune route ne lève.
- `tests/lib/contrat-envoi-a-jour.test.ts` : le nombre en dur de documents passe de 9 à 10 (mise à jour, pas un affaiblissement) ; les autres lots qui ajoutent un yaml toucheront la même ligne : en cas de conflit, additionner.
- Type d'alerte R14 (`reputation_mauvaise`) : R14 n'est pas sur `main` ; l'alerte passe par `Alerte::envoyer` existant avec le motif dans le titre.
