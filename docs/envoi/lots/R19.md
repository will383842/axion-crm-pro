# R19 — Bilan de couverture du contrat d'envoi

## Objet
Dernier lot du plan des routes. Vérifier, par un test, que chaque couple méthode + chemin des contrats yaml d'envoi (`backend/openapi/envoi/*.yaml`) est soit servi par une vraie route Laravel, soit déclaré « non servi au palier 0 » (409 ou 501), et qu'aucune route `/envoi/*` n'existe sans contrat. Aucune fonction ni route nouvelle : le lot constate.

## Méthode
- `tests/Feature/Envoi/CouvertureContratEnvoiTest.php` lit tous les yaml d'envoi, lit `Route::getRoutes()` (préfixe `/api/v1` retiré, paramètres `{id}` ramenés à `{}`), puis compare dans les deux sens.
- `tests/Support/NonServiAuPalier0.php` : liste explicite (code 409 ou 501 + raison en une phrase). Une entrée n'est admise que si la route existe ; `tests/Feature/Envoi/NonServiAuPalier0Test.php` fait l'appel et exige le code annoncé.
- Un chemin sans route n'entre PAS dans cette liste : c'est un trou réel, déclaré dans `TROUS_REELS` du test principal (un test `->todo()` par trou, la CI reste verte, le trou reste visible). Le test vérifie que chaque trou déclaré est bien un trou ; un trou comblé doit en sortir.
- `/desinscription/{jeton}` (page publique) est servi sans préfixe `/api/v1` : accepté tel quel.

## Résultat
- Couples méthode + chemin dans les contrats : **108**.
- Servis par une route réelle : **89**.
- Servis au palier 0 par 409/501 (liste `NonServiAuPalier0`) : **0** (aucune route présente sur `main` n'est dans ce cas).
- Trous réels : **19**.
- Routes `/envoi/*` sans contrat (sens inverse) : **0**. Hors périmètre `/envoi`, trois routes de notifications ne figurent pas au contrat (`read-all`, `test-alerte`, `{n}/read`).

## Trous réels
Aucune route : un appel répondrait 404, pas 409/501. À traiter par les lots propriétaires, sans nouvelle fonction dans R19.
- Boîtes (`routes/envoi/boites.php` vide) : `GET /envoi/boites`, `POST /envoi/boites`, `GET /envoi/boites/{id}`, `POST /envoi/boites/test-connexion`, `POST /envoi/boites/{id}/reactiver`, `POST /envoi/boites/{id}/suspendre`, `PUT /envoi/boites/{id}/reglages`.
- Chauffe (`chauffe.php` vide) : `GET /envoi/chauffe`, `POST /envoi/chauffe/{id}/reculer`.
- Séquences (`sequences.php` vide) : `GET /envoi/sequences`, `GET /envoi/sequences/{id}`, `POST /envoi/sequences/{id}/pause`, `POST /envoi/sequences/{id}/reprise`.
- Socle : `GET /envoi/etat`, `GET /envoi/compteurs`, `POST /envoi/tout-arreter`, `POST /envoi/reprendre`.
- Santé : `POST /envoi/sante/test`.
- Notifications : `POST /notifications/{id}/lue` (la route réelle est `POST /notifications/{n}/read`, chemin différent).

## Garde-fous
`ENVOI_REEL_ACTIF=false` inchangé. Aucune migration, aucune route, aucun envoi. `GardeDesPortsBrancheeSurLaProductionTest` et `envoi_drapeaux_garde` non touchés.
