Cahier : `X1-L3-cahier.md`. Aucune migration, aucune inscription, aucune ligne de matérialisation, aucun envoi, aucun drapeau touché.

## Écarts entre le cahier et le code / entre cahier et cahier
1. **Statut `en_cours` (test 5).** Une campagne `en_cours` est toujours reliée ; l'étape 4 (reprise par le lien) précède le contrôle du statut (étape 5). Résultat : `dejaFaite = true`, sans écriture, et non `statut_non_programmee`. Le test vérifie ce comportement (brouillon et `a_valider` donnent bien `statut_non_programmee`).
2. **Numéros de ligne** : vérifiés dans le code ; seuls l'en-tête, `transitionner()` et le test `CampagnesModeleDbTest` ont été retrouvés à l'emplacement décrit par le texte (pas par les numéros).
3. **`version_perimee`** levée par `lierSequence` pendant `construire` est convertie en `ConstructionRefusee('concurrence', réessayable)` : L4 ne voit qu'un seul type d'exception.
4. **Tests hors/dans transaction** : `RefreshDatabase` ouvre toujours une transaction ; les tests de `lierSequence` hors transaction et de la relance rejouent donc `DB::rollBack()`/`beginTransaction()` autour de l'appel (`cnsHorsTransaction`).
5. Contenu refusé : le contrôle de contenu accepte une adresse e-mail dans le corps ; le test utilise une balise `<script>`.
