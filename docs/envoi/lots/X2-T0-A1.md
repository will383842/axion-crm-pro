# Lot X2 vague 1 — T0 + A1 : branchement préparé, jamais activé

## Contexte
Une revue a montré que le transport d'envoi réel n'est pas branché. Ce lot prépare le branchement SANS l'activer : aucun drapeau
(`ENVOI_REEL_ACTIF`, `ENVOI_K1_ACTIF`, `ENVOI_SANTE_ACTIF`…) n'est touché, aucun nouvel interrupteur, la liste d'adaptateurs reste `[]`.

1. `config('envoi.reel_actif')` est faux sans variable d'environnement ; `PorteEnvoiReelle::ouverte()` reste faux même avec un
   `RetraitEnvoisEnFile` « réel » lié par `app()->instance`.
2. Domaine kumo + feu vert simulé accordé (par `DecisionFeuVert`) + DNS vert du jour + fabriques espionnes : `injecter` lève
   `envoi_reel_inactif` ; `pause`, `reprise`, `sante`, `etat`, `etatEnvoi`, `lireEvenements` laissent le compteur de fabriques à 0
   VIA LA PASSERELLE (porte fermée : rien n'est transmis), aucune requête HTTP (`Http::preventStrayRequests()` + `Http::assertNothingSent()`).
   Appelée DIRECTEMENT sur l'aiguilleur, `pause()` construit les adaptateurs portés par un domaine MÊME porte fermée (stop = sens sûr) :
   le test (2 bis) le documente (compteur à 1).
   Le test (2 ter) fixe l'ordre des fournisseurs : pour `envoi.serveur_interne`, l'aiguilleur de `AiguillageServiceProvider`

   (la passerelle ne le résout pas elle-même : le conteneur le lui injecte).

## A1 — `AiguilleurServeurEnvoi`
- Signature : `array<string, Closure(string $workspaceId, string $domaine): ServeurEnvoi> $fabriques`.
- Cache `construits` supprimé : un adaptateur est construit à chaque usage pour l'espace et le domaine courants (l'aiguilleur vit dans
  un singleton ; en worker de longue durée l'espace B recevait l'adaptateur de l'espace A).
- `etatEnvoi($id)` (contrat : l'identifiant rendu par `injecter`) résout l'adaptateur dans le contexte d'espace (RLS) :
  `envoi_injections_locales` d'abord, PUIS `envoi_injections_smtp` (l'UUID rendu par l'adaptateur smtp, jamais écrit dans
  `envoi_injections_locales`). Sans ligne ou identifiant non UUID (faux serveur : `sim-N`) : le faux serveur répond s'il est le seul
  actif, sinon `Inconnu` (plus de `actifs()[0]`). Un adaptateur réel n'est interrogé que si les trois conditions valent encore.
- Kumo : décision d'architecte, le registre durable écrira PLUS TARD `envoi_injections_locales(id_injection = id Kumo, adaptateur =
  'kumo')` avant le réseau. Ce chemin est déjà accepté et testé avec une ligne posée comme le fera le registre ; la production ne
  l'écrit PAS encore.
- Domaine passé à la fabrique par `etatEnvoi` : celui de la boîte pour smtp quand il est connu ; sinon le premier domaine vert de
  l'adaptateur (limite : `envoi_injections_locales` ne porte pas le domaine).
- `pause()` : TODO M1 dans le code et test `skip` « M1 : pause globale tous espaces avant de lier une fabrique » (ESCALADE, non implémenté).
- `pause()` sans contexte : comportement sûr inchangé (adaptateurs portés par un domaine, même porte fermée), documenté en commentaire ;
  les fabriques reçoivent alors l'espace courant ou `''` et le domaine `''`.
- Les fabriques ne doivent ouvrir AUCUNE connexion à la construction (documenté en en-tête).
- `AiguillageServiceProvider` : signature seulement, liste toujours vide.
